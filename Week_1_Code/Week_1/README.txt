WEEK 1 - FIRST LLM API CALL USING OPENAI

1. Install:
   python -m pip install -r requirements.txt

2. Copy .env.example to .env and add your OpenAI API key.

3. Run:
   python openai_call.py

A valid API key and available API billing/credits are required. Never share your
API key or upload your real .env file.
